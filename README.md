# Login Goiana

Tela de login em React + Vite, inspirada no site da Prefeitura de Goiana, PE.

[Ver a página](https://wesleyttiago.github.io/goiana-login-react/)

## Rodar no computador

Com Node.js 22.12 ou superior instalado:

```bash
npm ci
npm run dev
```

É só a tela, sem login real. Projeto de estudo, sem vínculo com a prefeitura.
